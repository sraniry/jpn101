# Fichiers archivés

Ces fichiers ne sont référencés nulle part dans l'application. Ils sont conservés ici
plutôt que supprimés, car deux d'entre eux ont une valeur de sauvegarde.

- `nihongo-progression-2026-07-02.json` — **sauvegarde de progression** exportée le 2 juillet 2026.
  Restaurable via « Mes phrases » → ⬆ Importer (.json).
- `nihongo-kyoto-v7.html` — ancienne version monolithique de l'app (avant le découpage en modules ES).
  Conservée comme référence historique.
- `nouvelles_phrases.js` — brouillon de phrases jamais intégré au pack.
- `kanji.js` — ancien jeu de 79 kanji de l'onglet Alphabet. Ses caractères étaient tous
  inclus dans les 103 de `data/jlpt-n5.js`, avec moins d'information (pas de lectures
  on/kun, pas de radicaux). Les deux vues ont été fusionnées dans JLPT N5 → 漢字.
